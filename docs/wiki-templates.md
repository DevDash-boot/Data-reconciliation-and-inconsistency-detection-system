# Wiki 페이지 템플릿

사용법
- 각 `## 페이지: ...` 구간을 GitHub Wiki의 새 페이지로 복사하세요.
- 페이지 이름은 괄호 안의 이름을 권장합니다. (`Home`은 기본 페이지)
- `< >` 와 `(예: ...)` 는 지우고 실제 내용으로 바꾸세요.
- 사이드바(`_Sidebar`)는 맨 아래 템플릿을 쓰면 목차가 항상 보여요.
